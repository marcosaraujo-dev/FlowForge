Quando usar Acordeões

✓ Use acordeões quando

  • O conteúdo pode ser agrupado em seções opcionais
  • Usuários raramente precisam ver todas as seções ao mesmo tempo
  • A tela ficaria longa demais sem colapsar grupos
  • São seções de configuração avançada ou detalhes secundários

✗ Não use acordeões quando

  • O usuário precisa comparar dados entre seções
  • As seções são curtas (use scroll direto)
  • São etapas de um processo sequencial (use stepper)
  • O conteúdo pode ser organizado em tabs
