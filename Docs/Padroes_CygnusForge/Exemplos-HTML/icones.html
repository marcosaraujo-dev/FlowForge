           Text="&#xE70F;"
           FontSize="14"
           Foreground="{StaticResource PrimaryColor}"/>

    <StackPanel Orientation="Horizontal" >
        <TextBlock FontFamily="Segoe MDL2 Assets" Text="&#xE710;" Margin="0,0,6,0"/>
        <TextBlock Text="Novo Funcionario"/>
    </StackPanel>
</Button>
Como usar em aplicacoes Web (HTML/CSS)

A fonte Segoe MDL2 Assets esta instalada por padrao em todo Windows (8.1+). Em sistemas internos — como portais web corporativos, Electron, WebView2 — ela funciona diretamente no browser sem necessidade de hospedar o arquivo de fonte. 

/* CSS — aplicar a fonte */
.icon {
  font-family: "Segoe MDL2 Assets";
  font-size: 20px;
  color: #184194;
}

/* Exemplo com variavel CSS para consistencia */
:root { --icon-font: "Segoe MDL2 Assets"; }
.icon { font-family: var(--icon-font); }
<!-- HTML — uso basico -->
<span class="icon">&#xE710;</span>
<span class="icon" style="color:#dc3545;">&#xE74D;</span>

<!-- Botao com icone + texto -->
<button style="display:flex; align-items:center; gap:8px;">
  <span style="font-family:'Segoe MDL2 Assets';">&#xE710;</span>
  <span>Novo</span>
</button>
Limitacao: Segoe MDL2 Assets e uma fonte do sistema Windows. Em Mac ou Linux o icone nao sera exibido a menos que o arquivo de fonte seja hospedado no servidor. Para sistemas internos Windows (ERP, portais corporativos) isso nao e problema. Para apps publicos na internet, prefira alternativas como Fluent UI Icons (SVG) ou Material Icons.
