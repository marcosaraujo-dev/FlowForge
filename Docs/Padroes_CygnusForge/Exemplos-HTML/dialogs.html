Regras de Uso
✓ Use dialogs para
  • Confirmação antes de ações destrutivas
  • Edições rápidas sem trocar de página
  • Exibir detalhes sem perder contexto da lista
  • Fluxos curtos em até 4 etapas (wizard)
✗ Evite dialogs para
  • Fluxos complexos com muitas etapas
  • Grandes quantidades de dados
  • Dialogs dentro de dialogs
  • Abrir automaticamente sem interação do usuário
