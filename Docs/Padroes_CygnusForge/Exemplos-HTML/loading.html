Loading Overlay

Loading Inline — Botão

O botão mostra spinner durante a execução. Desabilitado enquanto processa para evitar cliques duplos.

Quando usar cada abordagem
DURAÇÃO ESTIMADA ABORDAGEM EXEMPLO
< 300ms Nenhuma — resposta instantânea Filtro local em memória
300ms — 1s Loading inline (botão ou campo) Salvar formulário, busca rápida
1s — 3s Overlay ou Skeleton Carregar lista, abrir tela
> 3s Overlay com mensagem descritiva Geração de documentos, processamento
Desconhecido Overlay com opção de cancelar Importação, exportação em lote
