Correto e Incorreto
 Correto
HomeMeus TemplatesEditar: Acordo
Nomenclatura consistente com o titulo da pagina. Ultimo item em negrito, sem link.
Nivel maximo: 4 niveis (Home > A > B > C)
Hierarquia clara, usuario nao se perde.
Atualizar breadcrumb em TODA navegacao, incluindo botao Voltar
Estado sempre reflete onde o usuario esta.
 Incorreto
Inicio / Templates / Editar Template / Edicao Atual
Separador "/" inconsistente. Nomenclatura diferente dos menus. Item atual como link.
Breadcrumb em Dialog ou Modal
Dialogs nao tem hierarquia de pagina. Use o titulo do dialog.
Breadcrumb em tela de Wizard (usa Stepper)
O Stepper ja comunica o progresso das etapas — breadcrumb e redundante.
Implementacao WPF — Resumo

O BreadcrumbControl ja esta implementado em Controls/BreadcrumbControl.xaml.

PropriedadeTipoDescricao
Path string Caminho no formato "Home > Categoria > Item"
Separator string Separador entre itens. Padrao: " > "
NavigateCommand ICommand Executado ao clicar num item. Recebe a Key do item.
Items ObservableCollection<BreadcrumbItem> Alternativa ao Path para controle total de keys.
Padrao obrigatorio — Atualizar ao navegar
// No MainViewModel — todo metodo de navegacao deve definir ambos
PageTitle = "Editar: Acordo de Compensacao";
Breadcrumb = "Home > Meus Templates > Editar: Acordo de Compensacao";
