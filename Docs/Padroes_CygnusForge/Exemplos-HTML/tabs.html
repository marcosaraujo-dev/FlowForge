Tabs — Abas de Navegação

Três variantes para organizar conteúdo em categorias alternáveis

Underline Tabs — Padrão

Variante padrão. Tab ativa tem underline na cor PrimaryColor. Usar em páginas principais e telas de detalhe.

Dados Gerais
Documentos
Histórico
Relatórios
Aba Dados Gerais — conteúdo principal do registro. Campos de nome, empresa, cargo, data de admissão, etc.
Aba Documentos — lista de documentos vinculados ao trabalhador. RG, CPF, CTPS, contratos, etc.
Aba Histórico — log de alterações, movimentações salariais e eventos do trabalhador.
Altura do header: 40px Padding: 10px 20px Underline: 2px solid PrimaryColor Ativo: PrimaryColor + SemiBold Inativo: TextSecondaryColor

Use badges para indicar contagem de itens pendentes. Use ícones para reforçar o significado da aba.

Boxed Tabs

Abas com fundo preenchido. A ativa tem fundo branco sobre o header cinza. Ideal dentro de cards e grupos de configuração.

Configuração
Permissões
Auditoria
Configurações gerais do módulo: parâmetros, integrações, preferências de exibição.
Controle de acesso por perfil e usuário. Definição de permissões de leitura, escrita e exclusão.
Registro de ações realizadas: quem fez, o quê, quando.
Header fundo: BackgroundColor (#F0F2F5) Tab ativa: fundo branco Border radius: 6px 6px 0 0
